# Flutlicht

Fußballmanager im Stil der DOS-Klassiker. Start in der Saison 1994/95 mit Bundesliga und 2. Bundesliga, DFB-Pokal, Europapokal, Stadionausbau, Jugend, Transfers, Konferenz-Ticker und Hotseat für bis zu vier Manager.

Läuft als installierbare Web-App auf Mac, iPhone und iPad, auch offline. Musik und Stadionsounds werden im Browser erzeugt.

Installation und Hosting: siehe [LIESMICH.md](LIESMICH.md).
